# 人格包：default

> **状态**：模板，可直接改
> **日期**：2026-11-05
> **读者**：要写自己那一版人格的人
> **上游材料**：[人格引擎契约](../../docs/reference/contracts-persona.md)

这一份是**模板**，不是成品。尖括号里的话整行替换掉 —— 没删的话它会原样进模型的上下文。

## 五个文件

| 文件 | 进提示的位置 | 写什么 |
|---|---|---|
| `personality.md` | `## 我是谁` | 身份 + 性格 + 在意什么。越短越好 |
| `behavior.md` | `## 什么时候说话` | 判断与口味：接什么、什么时候闭嘴 |
| `reply_style.md` | `## 怎么说话` | 长短、语气、标点、口头禅 |
| `examples.md` | `## 举例：它平时是怎么说话的` | 「别人说 → 它回」几组。**最管用的一段** |
| `core.md` | 单独一段（手写记忆） | 关于它自己、关于主人 |

`identity.example.json` 是主人名单的样例：改名成 `identity.json` 填上平台用户 id，这个人就是 owner。

**不要写引擎已经管的事**：回复延迟、拆句、引用档位、限速、被 @ 必回、要不要进来看（判官管）。这些写死在代码里，写进人格不会改变行为。

## 生效方式

人格文件是**每次投递时读的**，改完不用重启，下一条消息生效。

部署到实例上：

```bash
node scripts/deploy.mjs --ssh <别名> --container <容器> --persona personas/default
```
